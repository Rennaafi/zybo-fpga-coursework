# FSM & Sequential Design

Five small FSM exercises, each self-contained:

- **vending-machine/** — coin-driven vending machine FSM with debounced/one-pulse inputs, includes board constraints and two testbenches
- **automatic-door-mealy/** — automatic door modeled as a Mealy machine
- **traffic-light-moore/** — traffic light modeled as a Moore machine
- **coffee-vending-practice/** — simplified vending FSM practice variant
- **digital-lock-key/** — 4-digit keypad-style lock: switch-entered digits, password check against parameters, unlock/wrong-password LED outputs, edge-detected button inputs
